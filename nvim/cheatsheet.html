The one concept: nvim has modes. In Normal mode, letters are commands, not text. That is the entire learning curve.

Esc always returns to Normal — press it whenever you are lost. Press Space alone and wait: a menu of every custom command pops up.

You have two GitHub accounts. kilo9alfa is active by default; david4aero is for DataBeacon work. gh uses whichever is active — check before opening a PR, because it is easy to file one as the wrong person.

gh and git identities are independent. `~/code/analytics/` switches git to david4aero automatically; gh does not follow. Check both before committing or opening a PR.
